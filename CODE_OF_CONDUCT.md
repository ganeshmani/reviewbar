# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the code, not the person. Harassment, insults and personal attacks aren't tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer privately through [GitHub](https://github.com/ganeshmani). Reports are kept confidential. The maintainer may remove comments, lock threads or block people who break these rules.
